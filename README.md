# Tangible-Interfaces-zur-Unterstuetzung-bewusster-Projektwechsel
## Abschlussprojekt Forschungsseminar MMI  

Dieses Projekt untersucht, wie sich ein Tangible User Interface auf Aufgabenwechsel in digitalen Arbeitsumgebungen auswirkt. Nutzer bearbeiten mehrere parallele Aufgaben in einem einfachen Interface, bestehend aus einem Tab Menu, und wechseln dabei entweder digital über das klicken auf Tabs oder physisch durch Tokens zwischen den Projekten. Ziel ist es zu analysieren, ob physische Interaktion Aufgabenwechsel bewusster macht und das Gefühl von Fokus und Kontrolle verbessert.

Die Anwendung simuliert die typischten, existierenden Unterbrechungen (E-Mails/Nachrichten, kurze Zwangsunterbrechungen) durch Pop-ups, Benachrichtigungen und zusätzliche Aufgaben. Dabei werden automatisch Daten wie Tabwechsel, Verweildauer, Reaktionszeit und Fehler geloggt.  
Aufgaben bestehen aus:  
- kontinuierliche Hauptaufgabe mit Texteingabe  
- kurzfristige Reaktionsaufgabe  
- kleine Benachrichtigungs-/Entscheidungsaufgaben

Das System exportiert und downloaded alle Interaktionsdaten automatisch als CSV-Datei für die Auswertung.
